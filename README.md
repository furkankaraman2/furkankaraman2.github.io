# Furkan Karaman Scientific Portfolio

Recruiter-focused bilingual scientific portfolio built with React and Vite.

## Easy content updates

- Edit profile, dates, skills, projects, visibility and report access in `src/content/portfolio.js`.
- Replace the profile image at `public/images/profile/furkan-karaman.webp`.
- Replace the downloadable CV at `public/documents/Furkan_Karaman_CV.pdf`.
- Set `visible: false` to hide an experience or project.
- Set `reportAccess` to `full`, `preview`, or `hidden`.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm test
npm run build
```

Pushes to `main` deploy automatically to GitHub Pages through GitHub Actions.
